# Security Policy

## Supported versions

Until the first stable release, security fixes are provided for the latest
published version of `nimble-agent-framework`.

## Reporting a vulnerability

Please report suspected vulnerabilities privately to
[security@nimbleway.com](mailto:security@nimbleway.com). Include the affected
version, impact, and reproduction steps when possible.

Do not open a public GitHub issue for an undisclosed vulnerability. Nimbleway
will acknowledge the report and coordinate remediation and disclosure with the
reporter.
